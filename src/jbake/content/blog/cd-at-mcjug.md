This past Wednesday night, I gave a presentation to the [Montgomery Country Java User's Group](https://sites.google.com/site/mcjugmd/home "Montgomery County Java User's Group") on Continuous Delivery.  I was lucky enough to be given the opportunity to speak to a  smart and attentive audience, and I look forward to going back and giving another presentation in the future.  I want to thank [Victor Semenov](https://x.com/victorsemenov "Victor Semenov at Twitter"), who organizes the MCJUG, for setting this up.

The presentation serves as an introduction to the concept and practices of Continuous Delivery.  The presentation cover the concept and need for continuous delivery, and then talks about the core practices necesarry for continuous delivery, such as:

- Agile
- Configuration Management
- Continuous Integration
- Testing
- Build Pipelines

I intended to cover both the core practices as well as tools, but I ran out of time.  In the future, I will likely break this presentation up into two halves that cover an introduction, and then a specific roadmap with tools and techniques.
