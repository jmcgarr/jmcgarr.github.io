## Method

```
./gradlew clean bake
rsync -a --prune-empty-dirs --exclude '*-draft.html' build/jbake/ build/site/
lychee --no-progress --root-dir "$PWD/build/site" \
  --user-agent 'Mozilla/5.0 (Macintosh; Intel Mac OS X 14_0) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.0 Safari/605.1.15' \
  --max-concurrency 6 --timeout 30 --max-retries 3 --retry-wait-time 5 \
  --exclude '^file://[^/]' --exclude 'linkedin\.com/sharing' --exclude 'x\.com/intent' --exclude 'bsky\.app/intent' --exclude '^mailto:' \
  --format json --output lychee.json 'build/site/**/*.html'
```

- Run 2026-10-11 from macOS (Apple Silicon), {'secs': 94, 'nanos': 272131625}.
- **Excluded:** protocol-relative embeds (as in CI), the per-post **share-intent** links (LinkedIn, X, Bluesky), which are compose forms rather than pages, and `mailto:`.
- Each failure was re-checked with a browser-like `curl` request (Safari User-Agent, `Accept: text/html`) to tell anti-bot answers from real failures.
